_Isko-Box App is a web-based voting system designed to streamline and secure voting processes at PUP-Lopez Campus._

## About the Project

The Isko-Box App simplifies elections and polls for PUP-Lopez Campus, making it easy and secure for students and faculty to vote online. By moving away from in-person and paper-based methods, the app reduces hassle, improves accessibility, and provides a transparent voting process for everyone involved.
